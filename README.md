# Atlantis Paradise Island — Family Adventure Guide

Interactive single-page guide to Atlantis Paradise Island, built by **Kelli Johnson**, Family Adventure Advisor (Independent Advisor with travelmation).

Live at **https://winnerkellij.github.io/atlantis**

Reusable template — one URL serves every family Kelli books to the resort. Personalization happens client-side via URL parameters Kelli includes in the link she sends, with a "Make this yours" panel for manual edits.

## Stack

Pure vanilla HTML / CSS / JavaScript. No framework, no build step. Hosted on GitHub Pages.

## Design + source

Design spec, brand system, and source notes live in the parent folder at `client-content/atlantis-paradise-island/` of [the Travel working repo](https://github.com/WinnerKelliJ) — not committed to this site repo.
